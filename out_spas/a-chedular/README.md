# 개요
제목: A-chedular
부제목: 관심사 기반으로 교내 강연을 추천하고 일정까지 관리해주는 서비스
참여자: 심용석, 이우석, 김영연, 문가연, 손원
참여자 메일:
서브도메인 후보 1개: a-chedular

원본 PDF: https://pub-11820c5f91164abc8e3e6e6bb3459741.r2.dev/designton/1770527530801-designton-2024-team5-A_schedular.pdf

## 프로젝트 설명
강연 공지가 너무 많거나 찾아보기 번거로워 관심이 있어도 참여로 이어지지 않는다는 학생 인터뷰에서 출발했습니다. 학교 행사·강연 정보를 한곳에서 확인하고 일정에 바로 추가할 수 있게 했고, 관심 키워드 기반 콘텐츠 필터링으로 강연을 추천·알림합니다. Tesseract-OCR로 포스터 이미지에서 강연 정보를 추출하는 방식도 제안했습니다.
