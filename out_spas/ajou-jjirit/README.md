## 프로젝트 설명
동아리는 부담스럽고 기존 모임 앱은 연애 목적이 많아 신뢰하기 어렵다는 학생 인터뷰에서 출발했습니다. 아주대 학생끼리 24시간 안에 모집하고 당일 만나는 가벼운 번개모임을 목표로, 공부·운동·게임·밥&술 같은 소모임 카테고리, 즉흥적인 모집, 위치 정보 아이콘을 제공하고 평가 지표로 신뢰성을 높였습니다.
