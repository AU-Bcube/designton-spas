## 프로젝트 설명
기업이 실무 경험을 요구하면서 멘토링 수요는 늘었지만, 유료 컨설팅은 비싸고 신뢰하기 어렵고 기존 플랫폼은 나에게 맞는 멘토를 찾기 어렵다는 문제를 다뤘습니다. 재학생 설문을 바탕으로 온보딩 데이터 기반 졸업생 멘토 추천·매칭, 가이드라인에 따른 포트폴리오 관리, AI 챗봇을 활용한 자소서 첨삭과 모의면접 기능을 기획했습니다.
