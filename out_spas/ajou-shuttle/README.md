## CSV 프로젝트 소개

셔틀버스 위치를 알 수 없고 운행 공지와 시간표가 홈페이지·에브리타임 등에 흩어져 있어 학생들이 불편을 겪는다는 문제에서 출발했습니다. 총무팀 담당자 인터뷰, 정류장 스티커 설문, 학생 설문, 2023~2025 노선별 이용 데이터 분석으로 근거를 쌓았습니다. 노선별 실시간 버스 위치와 정류장 지도, 운행 공지 알림, 학생증 QR 인증, 오류 신고·피드백 기능을 담았습니다.

- 프로젝트 유형: 앱 / 교내 교통 정보 서비스
- 진행 기간: 2025.04.14 ~ 2025.06.11
