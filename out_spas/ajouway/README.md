## 프로젝트 설명
원하는 정보를 빨리 찾기 어렵고, 신입생과 선배 간 소통이 어렵고, 학과 공지를 제대로 받지 못하는 신입생의 불편함을 다뤘습니다. 캠퍼스맵과 정보공유게시판을 한 탭에 합쳐 지도와 관련 정보를 함께 볼 수 있게 했고, 커뮤니티와 실시간 톡을 더했습니다. 에브리타임과의 차별점, 기존 기능의 접근성 향상, 과도한 익명성 문제 개선을 기획의 중심에 두었습니다.
