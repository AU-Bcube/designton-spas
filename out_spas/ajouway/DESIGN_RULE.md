# AJOUWAY 디자인 규칙

## 디자인 컨셉
학교 블루와 길을 가리키는 화살표로 신입생을 캠퍼스 정보와 사람에게 연결하는 길잡이를 표현한다.

참고 발표 화면: `assets/page-00.jpg`, `assets/page-08.jpg`, `assets/page-17.jpg`. 아래 색상과 구성은 발표 화면을 바탕으로 웹에 적용하기 위한 제안이며, 색상 코드는 화면에서 추정한 값이다.

## 디자인 색상
- 주색: `#0069b5` - 브랜드와 주요 강조.
- 배경: `#eef6fd` - 넓은 면과 보조 영역.
- 본문·제목: `#15334e` - 밝은 배경 위의 텍스트.
- 흰색 - 정보 영역과 여백. 텍스트와 배경의 명도 대비를 확인한다.

## 디자인 컴포넌트
- 길찾기 헤더: 브랜드명과 방향 화살표로 탐색의 출발점을 표시한다.
- 지도·게시판 병치: 장소와 관련 정보 목록을 한 화면의 두 영역으로 구성한다.
- 커뮤니티 목록: 게시글 제목, 작성 맥락, 소통 주제를 행으로 정리한다.
- 개선 전후 비교: 익명성 문제와 제안한 해결 방향을 나란히 설명한다.

## 적용 원칙
- 발표 자료의 이미지와 서비스 설명은 해당 프로젝트의 `README.md`와 대조한다. 이미지는 `assets/`에 두고 상대경로로 불러온다.
- 모바일에서는 영역을 세로로 쌓고, 본문과 이미지의 크기를 읽기 쉽게 유지한다. 내비게이션은 같은 문서의 fragment로 연결한다.
- 위 화면은 서비스 기획을 설명하는 정적 표현이다. 실제 가입·예약·저장 등 서버나 로컬 저장소가 필요한 기능은 구현하지 않는다.
