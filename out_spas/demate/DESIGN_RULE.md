# DEMATE 디자인 규칙

## 디자인 컨셉
연두색과 부드러운 분홍빛 그라데이션으로 봉사 참여의 부담을 낮추는 웹 탐색 경험을 표현한다.

참고 발표 화면: `assets/page-00.jpg`, `assets/page-14.jpg`, `assets/page-29.jpg`. 아래 색상과 구성은 발표 화면을 바탕으로 웹에 적용하기 위한 제안이며, 색상 코드는 화면에서 추정한 값이다.

## 디자인 색상
- 주색: `#72a832` - 브랜드와 주요 강조.
- 배경: `#f2f9e7` - 넓은 면과 보조 영역.
- 본문·제목: `#314725` - 밝은 배경 위의 텍스트.
- 연한 분홍 - 연두색과 섞이는 그라데이션에 사용.
- 흰색 - 정보 영역과 여백. 텍스트와 배경의 명도 대비를 확인한다.

## 디자인 컴포넌트
- 봉사 탐색 그리드: 활동 이미지와 분야, 장소를 카드에 담는다.
- 관심사 선택 칩: 적성과 관심 주제를 짧은 선택지로 묶는다.
- 매칭 설명 패널: 관심사 입력에서 추천 결과까지의 흐름을 소개한다.
- 웹 브라우저 프레임: 발표 자료의 데스크톱 화면 비율을 살려 목록을 배치한다.

## 적용 원칙
- 발표 자료의 이미지와 서비스 설명은 해당 프로젝트의 `README.md`와 대조한다. 이미지는 `assets/`에 두고 상대경로로 불러온다.
- 모바일에서는 영역을 세로로 쌓고, 본문과 이미지의 크기를 읽기 쉽게 유지한다. 내비게이션은 같은 문서의 fragment로 연결한다.
- 위 화면은 서비스 기획을 설명하는 정적 표현이다. 실제 가입·예약·저장 등 서버나 로컬 저장소가 필요한 기능은 구현하지 않는다.
