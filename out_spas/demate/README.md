## 프로젝트 설명
개인주의 심화와 제도 변화로 봉사 참여율이 크게 줄었고, 기존 봉사 플랫폼은 인터페이스가 복잡해 참여 의지를 떨어뜨린다는 문제에서 출발하여, 관심사·적성 기반 AI 봉사 매칭과 쉬운 탐색 화면을 갖춘 웹 서비스를 기획·설계했습니다.
