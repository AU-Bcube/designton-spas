# Glo:meet 디자인 규칙

## 디자인 컨셉
밝은 블루와 연한 청회색 바탕, 겹쳐진 모바일 화면으로 교환학생과 재학생의 연결을 표현한다.

참고 발표 화면: `assets/page-00.jpg`, `assets/page-08.jpg`, `assets/page-16.jpg`. 아래 색상과 구성은 발표 화면을 바탕으로 웹에 적용하기 위한 제안이며, 색상 코드는 화면에서 추정한 값이다.

## 디자인 색상
- 주색: `#4f80ed` - 브랜드와 주요 강조.
- 배경: `#e4eafa` - 넓은 면과 보조 영역.
- 본문·제목: `#20345d` - 밝은 배경 위의 텍스트.
- 흰색 - 정보 영역과 여백. 텍스트와 배경의 명도 대비를 확인한다.

## 디자인 컴포넌트
- 관심사 프로필: 언어·문화·운동 등의 태그와 인물 정보를 묶는다.
- 매칭 카드 쌍: 두 사람의 공통 관심사를 가운데 연결선으로 보여준다.
- 모임 리스트: 주제와 참여 맥락을 간결한 행으로 정리한다.
- 폰 목업: 표지처럼 화면을 겹쳐 다양한 교류 장면을 소개한다.

## 적용 원칙
- 발표 자료의 이미지와 서비스 설명은 해당 프로젝트의 `README.md`와 대조한다. 이미지는 `assets/`에 두고 상대경로로 불러온다.
- 모바일에서는 영역을 세로로 쌓고, 본문과 이미지의 크기를 읽기 쉽게 유지한다. 내비게이션은 같은 문서의 fragment로 연결한다.
- 위 화면은 서비스 기획을 설명하는 정적 표현이다. 실제 가입·예약·저장 등 서버나 로컬 저장소가 필요한 기능은 구현하지 않는다.
