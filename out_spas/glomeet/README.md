## 프로젝트 설명
교내 교환학생 교류 프로그램은 조건이 까다롭고 일회성이라 재학생과 교환학생이 꾸준히 교류하기 어렵다는 문제에서 출발했습니다. 재학생·교환학생 인터뷰와 국제협력처 담당자 인터뷰, 설문조사로 니즈를 확인했고, 성향·관심사 기반 교환학생 매칭, 운동·여행·문화·언어 등 주제별 모임, 교환학생과 함께하는 이벤트 기능을 기획했습니다.

## 각 페이지 요약

### 0페이지 요약
서비스 표지와 스마트폰 목업.

### 1페이지 요약
교환학생과 재학생의 지속적인 교류 기회 부족.

### 2페이지 요약
재학생과 교환학생 3명의 인터뷰.

### 3페이지 요약
국제교류 담당자 인터뷰와 기존 교류 프로그램.

### 4페이지 요약
교환학생 교류 설문 결과 세 가지 막대 차트.

### 5페이지 요약

### 6페이지 요약
외국인과 소통하며 언어 능력을 기르고 싶은 사용자 페르소나.

### 7페이지 요약

### 8페이지 요약

### 9페이지 요약

### 10페이지 요약

### 11페이지 요약

### 12페이지 요약

### 13페이지 요약

### 14페이지 요약

### 15페이지 요약

### 20페이지 요약
