# Haru:ON 디자인 규칙

## 디자인 컨셉
하늘색에서 민트로 이어지는 부드러운 그라데이션과 둥근 형태로 예측 가능한 하루를 표현한다.

참고 발표 화면: `assets/page-00.jpg`, `assets/page-09.jpg`, `assets/page-18.jpg`. 아래 색상과 구성은 발표 화면을 바탕으로 웹에 적용하기 위한 제안이며, 색상 코드는 화면에서 추정한 값이다.

## 디자인 색상
- 주색: `#639de9` - 브랜드와 주요 강조.
- 배경: `#edf4ff` - 넓은 면과 보조 영역.
- 본문·제목: `#27486b` - 밝은 배경 위의 텍스트.
- 민트 - 하늘색과 이어지는 그라데이션에 사용.
- 흰색 - 정보 영역과 여백. 텍스트와 배경의 명도 대비를 확인한다.

## 디자인 컴포넌트
- 시각 루틴: 하루 순서를 그림과 짧은 문장으로 나열한다.
- 상황 시뮬레이션: 일상 장면을 단계별 이미지 카드로 소개한다.
- 감정 선택: 표정과 명확한 레이블을 함께 사용한다.
- 보호자 안내: 아동 화면과 보호자 기능을 구분해 설명한다.

## 적용 원칙
- 발표 자료의 이미지와 서비스 설명은 해당 프로젝트의 `README.md`와 대조한다. 이미지는 `assets/`에 두고 상대경로로 불러온다.
- 모바일에서는 영역을 세로로 쌓고, 본문과 이미지의 크기를 읽기 쉽게 유지한다. 내비게이션은 같은 문서의 fragment로 연결한다.
- 위 화면은 서비스 기획을 설명하는 정적 표현이다. 실제 가입·예약·저장 등 서버나 로컬 저장소가 필요한 기능은 구현하지 않는다.
