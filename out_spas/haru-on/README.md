## CSV 프로젝트 소개

발달장애 아동·청소년은 일상의 작은 변화에도 큰 불안을 느끼지만, 기존 서비스는 언어적 설명이나 반복 훈련에 의존하고 기능이 여러 앱에 흩어져 있으며 VR 등 장비 비용 부담이 크다는 문제를 다뤘습니다. 하루 일과를 미리 체험하는 시뮬레이션, 시각적 루틴·스케줄 관리, 감정표현 기능을 하나로 묶고, 보호자 기능과 커뮤니티로 가정에서도 꾸준히 활용할 수 있게 했습니다.

- 프로젝트 유형: 앱 / 발달장애 아동 일상 적응 서비스
- 진행 기간: 2026.03.24 ~ 2026.06.02
