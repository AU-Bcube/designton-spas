## CSV 프로젝트 소개

대학생 생활비 부담은 커지는데, 대학생 할인 정보는 인스타그램·카카오톡·에브리타임 등에 흩어져 있어 실제로 혜택을 챙기는 학생이 적다는 문제를 다뤘습니다. 설문으로 정보 분산과 최신 정보 부족을 주요 불편으로 확인했고, 카테고리별 혜택 정보, 위치 기반 혜택 지도, 단골 가게 찜과 혜택 알림, 내가 받은 혜택 분석 차트, 메인 화면 학생증 인증 버튼을 기획했습니다.

- 프로젝트 유형: 앱 / 대학생 혜택 정보 플랫폼
- 진행 기간: 2025.04.14 ~ 2025.06.11
