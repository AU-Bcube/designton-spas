## 프로젝트 설명
학부생 다수가 대학원에 대해 잘 모르고, 서비스를 쓰고 싶은 주된 이유가 정보 탐색이라는 설문 결과에서 출발했습니다. 대학원 연구 활동 소개, 졸업생 인터뷰, 실시간 멘토링을 한곳에 모아 대학원 진학을 고민하는 학생이 연구실별 활동과 특성을 구체적으로 파악할 수 있게 했습니다. 앱과 웹 와이어프레임을 함께 설계했습니다.
