## 프로젝트 설명
학기마다 쌓이는 교과·비교과 활동을 기록해두지 않아 취업 시기에 자소서와 포트폴리오에 담지 못하는 문제에서 출발했습니다. 마스코트 치토와의 대화 형식으로 활동을 기록하고, 기록량에 따라 치토를 키우고 랜덤·희귀 치토 컬렉션을 보상으로 줍니다. 학사서비스·아주허브와 연동해 교과 기록을 자동으로 불러오고, 종강 시점에 푸시 알림으로 기록을 유도하며, 자소서·포트폴리오 작성 시 적절한 기록을 추천합니다.
