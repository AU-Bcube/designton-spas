## 프로젝트 설명
학교 홈페이지의 캠퍼스맵은 찾아가기 번거롭고 건물·마커가 많아 보기 어렵고, 행사 공지는 카톡·메일로 흩어져 놓치기 쉽다는 문제를 다뤘습니다. 건물 검색과 위치·개방시간·층별 시설·편의시설 카테고리 확인, 카테고리별 행사 검색과 지도 위 위치 표시, 행사장 근처 알림과 리마인드 알림을 제공합니다. UGC 기반 도전과제와 난이도별 코인·랜덤박스 보상 같은 게임 요소로 시설 이용과 행사 참여를 유도합니다.
